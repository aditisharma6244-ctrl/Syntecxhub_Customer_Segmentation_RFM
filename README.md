# Customer Segmentation using RFM Analysis

## Project Overview
This project performs customer segmentation using RFM (Recency, Frequency, and Monetary) analysis. It analyzes customer transaction data to understand purchasing behavior and classify customers into different groups.

## Objectives
- Clean and prepare customer transaction data.
- Calculate Recency, Frequency, and Monetary metrics.
- Segment customers based on purchasing behavior.
- Visualize customer segments using a bar chart.
- Provide marketing recommendations for each customer segment.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib

## Methodology
1. Created a customer transaction dataset.
2. Checked and cleaned the data.
3. Calculated RFM metrics for each customer.
4. Assigned scores based on recency, frequency, and monetary value.
5. Classified customers into Loyal, New, At Risk, and Regular segments.
6. Visualized customer segments.
7. Generated targeted marketing recommendations.

## Project Files
- `Syntecxhub_Customer_Segmentation_RFM.ipynb` — Python notebook containing the analysis.
- `customer_segmentation_results.csv` — RFM scores, customer segments, and marketing recommendations.
- `cleaned_customer_transactions.csv` — Cleaned transaction dataset.

## Results
The project demonstrates how RFM analysis can help businesses identify valuable customers, recognize customers who may stop purchasing, and plan targeted marketing strategies.

**Note:** This project uses a small sample dataset created for learning and demonstration. The segmentation thresholds are illustrative and should be adjusted for real business data.
